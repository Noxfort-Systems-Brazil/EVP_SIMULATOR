# 🗺️ Движок рендеринга карт и асинхронные теплокарты

Данный документ описывает подсистему рендеринга карт и визуализации дорожного движения CARINA, расположенную в каталоге [`src/rendering/`](../../src/rendering). В нем подробно рассматриваются генерация статичных векторных карт из описаний дорожных сетей SUMO (`.net.xml`), пространственные проекции координат и асинхронная интерполяция теплокарт плотности в реальном времени.

⬅️ Назад в [Главный хаб документации](carina_moc.md) | 🖥️ См. [Интерфейс пользователя и дашборд](ui_and_dashboard.md) | 📈 См. [MFD и макроаналитика](mfd_and_analytics.md)

## 1. Архитектура подсистемы

CARINA предоставляет нативную геопространственную визуализацию без необходимости загрузки внешних тайлов картографических сервисов или закрытых облачных API. Подсистема рендеринга полностью автономна и работает в 100% офлайн-режиме:

```text
 Дорожная сеть SUMO (`.net.xml`) / Телеметрия
                      │
                      ▼
        ┌───────────────────────────┐
        │  map_coordinate_generator │ (Преобразование координат UTM/Декартовых -> Пиксели)
        └─────────────┬─────────────┘
                      │
        ┌─────────────┴─────────────┐
        ▼                           ▼
┌────────────────────────┐  ┌────────────────────────┐
│   static_map_renderer  │  │ async_heatmap_renderer │
│ (Полосы, узлы, фазы)   │  │ (Плотность KDE/Очереди)│
└───────────┬────────────┘  └───────────┬────────────┘
            │                           │
            └─────────────┬─────────────┘
                          ▼
            Нативный холст отрисовки Flet
            (`LiveCanvasMapWidget`)
```

## 2. Базовые модули каталога `src/rendering/`

### 2.1 Преобразование координат (`map_coordinate_generator.py`)
Расположен в [`src/rendering/map_coordinate_generator.py`](../../src/rendering/map_coordinate_generator.py):
- Преобразует двухмерные координаты сети SUMO $(x, y)$ в координаты виртуального холста вьюпорта $(u, v)$.
- Поддерживает плавное панорамирование, масштабирование (pinch-to-zoom) и автоматическое центрирование по охватывающему прямоугольнику (bounding box) всех активных светофорных объектов.
- Обеспечивает сохранение пропорций дорожного полотна при любых разрешениях мониторов.

### 2.2 Рендерер статичных векторных карт (`static_map_renderer.py`)
Расположен в [`src/rendering/static_map_renderer.py`](../../src/rendering/static_map_renderer.py):
- Разбирает геометрию полос, контуры перекрёстков и внутренние соединения файла SUMO `.net.xml`.
- Отрисовывает многополосные магистрали с разделительными линиями, указателями направлений движения и графическими символами светофорных колонок.
- Кэширует векторные пути в оперативной памяти, исключая повторные вычисления на CPU при неизменной сцене.

### 2.3 Рендерер асинхронных теплокарт (`async_heatmap_renderer.py`)
Расположен в [`src/rendering/async_heatmap_renderer.py`](../../src/rendering/async_heatmap_renderer.py):
- Использует **ядерную оценку плотности (Kernel Density Estimation — KDE)** для интерполяции непрерывных пространственных тепловых полей на основе дискретных метрик детекторов:
  - **Теплокарта плотности трафика:** Отображает концентрацию автомобилей на квадратный километр.
  - **Теплокарта времени ожидания и задержек:** Выделяет узкие места и «бутылочные горлышки» магистралей.
  - **Теплокарта риска заторов (Spillback):** Визуализирует пространственные волны образования пробок, прогнозируемые агентом Guardian.
- Выносит вычисление гауссова размытия и свертки матриц в фоновые рабочие потоки, исключая просадку частоты кадров GUI.

## 3. Конфигурация и цветовые градиенты теплокарт

Весовые коэффициенты и параметры теплокарт настраиваются в файле [`config/settings.ini`](../../config/settings.ini):

```ini
[HEATMAP_SCALING]
weight_occupancy = 1.0
weight_waiting_time = 1.5
weight_queue_length = 2.0
gaussian_kernel_radius = 24
color_ramp = viridis  # Поддерживаемые палитры: viridis, plasma, turbo, traffic_light
```
