Данный документ описывает конвейер экспертной объяснимости решений ИИ CARINA, расположенный в каталогах [`src/xai/`](../../src/xai) и [`src/sas/`](../../src/sas). ## 1. Архитектура судебной объяснимости (`src/xai/`)

В сфере муниципального управления транспортом принятие решений непрозрачными алгоритмами «черного ящика» юридически недопустимо для надзорных органов, счетных палат (Tribunal de Contas) и сертифицированных инженеров ЦОДД. CARINA обеспечивает **100% детерминированную математическую объяснимость** на каждом этапе:

```text
 ┌─────────────────────────┐          ┌───────────────────────────┐          ┌────────────────────────┐
 │  Глубокая нейросеть     │ ───────> │ Интегрированные градиенты │ ───────> │  Отчет ABNT NBR 14724  │ ───> Экспертный xai.docx
 │  (TCN + ST-GATv2 + D3QN)│          │ Google Captum (0% - 100%) │          │ 5 формальных уравнений │      (Муниципальный отчет)
 └─────────────────────────┘          └───────────────────────────┘          │  + таблица вето Guardian│
                                                                             └────────────────────────┘
```

Конвейер XAI базируется на модульной архитектуре построителей:
- [`src/xai/multi_agent_report_builder.py`](../../src/xai/multi_agent_report_builder.py): Координирует сборку муниципальных аналитических отчетов по всем объектам сети.
- [`src/xai/captum_attribution_engine.py`](../../src/xai/captum_attribution_engine.py): Рассчитывает атрибуцию градиентов вдоль траектории интерполяции от базовой линии к текущему входу.
- [`src/xai/network_attribution_aggregator.py`](../../src/xai/network_attribution_aggregator.py): Агрегирует значимость признаков в масштабе магистральных направлений.
- [`src/xai/report_block_registry.py`](../../src/xai/report_block_registry.py): Распределяет секции отчета по специализированным генераторам содержимого.

## 2. 5 формальных математических уравнений нейросетей (Раздел 2 отчета)

В строгом соответствии с требованиями административного аудита отчет CARINA включает 5 формальных уравнений LaTeX, определяющих функционирование каждого нейросетевого слоя:

### 2.1 Причинная расширенная свертка (TCN Локального агента)
$$\mathbf{y}(t) = (x *_d f)(t) = \sum_{i=0}^{k-1} f(i) \cdot x(t - d \cdot i)$$

### 2.2 Пространственно-временное графовое внимание (ST-GATv2 Lite)
$$\alpha_{ij}(t) = \frac{\exp\left(\mathbf{a}^T \text{LeakyReLU}\left(\mathbf{W} [\mathbf{h}_i \parallel \mathbf{h}_j]\right)\right)}{\sum_{k \in \mathcal{N}_i} \exp\left(\mathbf{a}^T \text{LeakyReLU}\left(\mathbf{W} [\mathbf{h}_i \parallel \mathbf{h}_k]\right)\right)}$$

### 2.3 Формулировка предиктивного автоэнкодера (PAE)
$$\mathcal{L}_{\text{PAE}}(\phi, \theta) = \frac{1}{N} \sum_{k=1}^N \| x_k(t + \Delta t) - g_\theta(f_\phi(x_k(t))) \|^2$$

### 2.4 Оценка ценности безопасности Dueling Q-Value агента Guardian (D3QN Veto)
$$Q(s, a) = V(s) + \left( A(s, a) - \frac{1}{|\mathcal{A}|} \sum_{a'} A(s, a') \right)$$

### 2.5 Интегрированные градиенты Captum (Аксиома полноты)
$$\text{IntegratedGradients}_i(x) = (x_i - x'_i) \times \int_0^1 \frac{\partial F(x' + \alpha(x - x'))}{\partial x_i} d\alpha$$

$$\sum_{i=1}^n \text{IntegratedGradients}_i(x) = F(x) - F(x')$$
